About UNIX Timestamps

What is a UNIX timestamp?

A UNIX timestamp is a system for describing a point in time, defined as the number of seconds that have elapsed since 00:00:00 Thursday, 1 January 1970, Coordinated Universal Time (UTC), minus leap seconds.
